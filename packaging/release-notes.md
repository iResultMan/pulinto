PuLinTo 1.0.0. Один из трёх способов установки (подробно: https://github.com/iResultMan/pulinto#установка-одной-командой).

**Одной командой в терминале:**

```sh
curl -fsSL https://iresultman.github.io/pulinto/install.sh | bash
```

**Установочным файлом:**

- Debian, Ubuntu, Mint: `pulinto-x86_64.deb` (двойной щелчок или `sudo apt install ./pulinto-x86_64.deb`);
- Fedora, RHEL, AlmaLinux, Rocky: `pulinto-x86_64.rpm` (`sudo dnf install ./pulinto-x86_64.rpm`);
- любой дистрибутив: `pulinto-x86_64.tar.gz`, внутри `./install.sh`.

Больше ничего делать не нужно. Контрольные суммы: `SHA256SUMS`.

Проверено на Ubuntu: XFCE (X11) и GNOME 50 (Wayland). Сборки для Red Hat и родственных систем не проверялись на живых машинах: нужны тестировщики ([как помочь](https://github.com/iResultMan/pulinto/blob/main/docs/TESTING.md)).

PuLinTo 1.0.0. One of three ways to install (details: https://github.com/iResultMan/pulinto/blob/main/README_EN.md#install-with-one-command).

**With one command in a terminal:**

```sh
curl -fsSL https://iresultman.github.io/pulinto/install.sh | bash
```

**With an installer file:**

- Debian, Ubuntu, Mint: `pulinto-x86_64.deb` (double click or `sudo apt install ./pulinto-x86_64.deb`);
- Fedora, RHEL, AlmaLinux, Rocky: `pulinto-x86_64.rpm` (`sudo dnf install ./pulinto-x86_64.rpm`);
- any distribution: `pulinto-x86_64.tar.gz`, with `./install.sh` inside.

There is nothing more to do. Checksums: `SHA256SUMS`.

Tested on Ubuntu: XFCE (X11) and GNOME 50 (Wayland). The builds for Red Hat and related systems have not been tried on live machines: testers are needed ([how to help](https://github.com/iResultMan/pulinto/blob/main/docs/TESTING.md)).
